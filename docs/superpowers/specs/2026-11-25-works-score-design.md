# 작품 점수: 종류와 만든 개수

## 왜
좌판(같은 상품의 낱개)이 생긴 뒤로 같은 종류를 1개 만들든 10개 만들든 브랜드 레벨이 같았다. 만드는 만큼 조금이라도 올라야 한다(작은 숫자가 오르는 재미).
다만 30종류를 하나씩 만드는 것과 한 종류를 30개 만드는 것은 들어가는 힘이 크게 다르다.

## 접근
- 낱개마다 1점: 잘 오르지만 30종류와 1종류 30개가 같아진다. 사용자가 거절.
- 종류와 개수를 따로 채점(구찌 생산량과 비교): 10개를 더 만들어도 0.1이 잘 안 오른다.
- 작업 시간으로 채점: 일기에 시간이 없는 날은 0점이 된다.
- **새 종류 1점 + 같은 종류를 더 만든 낱개는 1/10점 (선택)**. "일단 10개로 해보고 사용해가면서 조정" → 10은 설정값.

## 규칙
- 작품 점수 = 종류 + (개수 − 종류) ÷ 10. 레벨 곡선·가중치는 그대로.
- 종류 = 보이는 상품 수. 개수 = 낱개가 있으면 낱개 수, 없으면 1 (대표와 낱개를 겹쳐 세지 않음).
- 대표 상품을 숨기거나 지우면 낱개도 함께 빠진다. 팔린 것은 계속 센다. 레벨은 지금처럼 역대 최고 점수를 쓴다.
- 화면은 점수 대신 "3종류 · 32개". 최고 기록은 개수로 본다.
- 낱개는 올린 날짜(한국 시간)에 달력 사진으로 들어간다. 대표와 낱개를 같은 날 올렸으면 대표 사진은 뺀다.
- 비율은 설정에서 "몇 개를 더 만들면 새 종류 1개와 같은지"로 바꾼다. 바꾸면 과거 레벨도 다시 계산된다.

## 데이터와 배포 순서
`catalog_events.parent_id`(낱개일 때 대표 상품 id, 지워진 뒤에도 남음)를 추가하고 트리거가 낱개도 남긴다.
옛 코드는 낱개를 종류로 세고 새 코드는 열이 없으면 못 읽으므로: ① 열 추가 → ② 코드 배포 → ③ 트리거 교체와 이미 있는 낱개 채우기.
